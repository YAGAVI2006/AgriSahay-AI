# 🌾 AgriSahay AI

### AI-Powered Agriculture Decision Support System

AgriSahay AI is an intelligent Agriculture Decision Support System (ADSS) designed to empower farmers with AI-driven insights for smarter agricultural decision-making. The platform integrates crop recommendations, crop disease detection, weather forecasting, market insights, government scheme information, and an AI farming assistant into a single, user-friendly web application.

---

## 📖 Overview

Agriculture is one of the most important sectors, yet farmers often depend on multiple applications and websites for weather updates, crop selection, disease diagnosis, market prices, and government schemes.

AgriSahay AI addresses this challenge by providing an all-in-one AI-powered platform that delivers personalized recommendations and actionable insights, helping farmers make informed decisions and improve productivity.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/YAGAVI2006/AgriSahay-AI.git
```

### Navigate to the Project

```bash
cd AgriSahay-AI
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
